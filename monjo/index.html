Capabilities

What Monjo can actually do.

This is not a coding assistant. Monjo is an autonomous agent with real system access — the gap between "suggests changes" and "ships them" is the entire point.

⚡

Simultaneous dual-model execution

Both models run in parallel — the sandbox model reasons and generates while the exec model carries out the previous instruction. No waiting between think and do.

🗺

Deep codebase awareness

The sandbox model maps your entire project — imports, dependency graph, build config, test suites — before touching a single file. It understands your architecture the way a senior engineer would.

⚙️

Tiered bypass permissions

Standard: file edits only. Elevated: + terminal, CMD, and package managers. Full: complete autonomous system control. Monjo operates exactly within what you grant.

🖥

Full terminal + CMD access

At elevated bypass, the exec model has real shell access — npm, pip, git, compilers, test runners, build scripts, any CLI your project needs. It runs them, not simulates them.

🔒

Fully local — code never leaves

Monjo is a native Windows Electron app. Your codebase is never uploaded, synced, or sent to any server. Only AI inference calls leave your machine.

🔗

How it works

How the dual-model engine runs.

Both models fire simultaneously from the moment you start a session. The sandbox model never slows the exec model down — they operate in parallel, coordinating in real time.

01

Define the task

Give Monjo an engineering brief in plain language. It treats it as a real task — not a chat message. Set your bypass level before execution begins.

02

Sandbox model activates

The sandboxed Anthropic model indexes your codebase, maps architecture, and plans the full sequence of changes — with zero system access, zero risk.

03

Exec model fires in parallel

As the sandbox model plans, the executive model begins executing the completed steps — writing files, running terminal commands, installing packages — simultaneously, not sequentially.

04

Continuous coordination

The two models coordinate throughout the session — sandbox verifies exec output, flags issues, and adjusts the plan. Work ships while verification is still running.
